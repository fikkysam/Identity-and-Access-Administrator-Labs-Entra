## Notes

. These screenshots show catalog configuration and discovery evidence.

. The unsanctioned status does not, by itself, prove that endpoint access was blocked. Endpoint enforcement requires supported Microsoft Defender for Endpoint onboarding and integration with Defender for Cloud Apps; that test remains unverified.

. Review screenshots for personal or tenant-identifying information before making them public.
